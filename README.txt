猫Todo UI再構成版

配置先:
C:\project\javapg\

含まれるもの:
- App.java
- static\todo.css
- static\todo.js
- static\assets\ 配下の画像18点

適用方法:
1. 現在の App.java / static\todo.css / static\todo.js をバックアップしてください。
2. このフォルダの内容を C:\project\javapg\ に上書きコピーしてください。
3. todos.db は変更・上書きしません。
4. これまでと同じ方法でコンパイル・起動してください。

主な変更:
- 元デザインを基準に全幅ヘッダーへ再構成
- 破り紙風タイトルバナー
- ヘッダー右の吹き出し＋眠る猫
- 左サイドバーの手帳風レイアウト
- ペン立て猫付き登録エリア
- 猫顔＋件数付き4タブ
- ルーズリーフ風Todo一覧
- サブタスク接続線
- 完了スタンプ
- 追加画像10点を静的配信ホワイトリストへ追加

変更していないもの:
- SQLiteテーブル構造
- 登録/サブタスク登録
- 検索
- 編集
- 削除
- 親子関係
- context-only仕様
- 完了/未完了トグル

補足:
タブ件数は todos テーブルから読み取り専用で集計します。DB構造の変更はありません。
